# Ubuntu Hello v1.0.2 - Subprocess Privilege Hardening & Bug Fixes

This release addresses a critical bug in subprocess privilege management under setuid/PAM environments and cleans up console output leaks.

---

## 🔒 Subprocess Privilege Hardening

*   **Subprocess Privilege Management in PAM**:
    *   Fixed a bug where system shells (like `dash`) drop effective root privileges to the calling user's UID when spawned via `popen()` inside PAM authentication contexts.
    *   Temporarily set the real UID (RUID) to `0` (`setreuid(0, 0)`) during subprocess execution in `try_set_keyring_authtok` and `pam_sm_setcred`, enabling TPM keyring unsealing (`tpm2_createprimary`, `tpm2_load`, `tpm2_unseal`) to execute with proper root authority.
    *   Restored original user UIDs immediately after forking to preserve system security integrity.

## 🛠️ Bug Fixes & Improvements

*   **Console Output Silence**:
    *   Redirected stderr to `/dev/null` for `rm` operations during transient TPM context cleanups, preventing confusing `Permission denied` errors from polluting the user terminal.
