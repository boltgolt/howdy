# 🚀 Ubuntu Hello v1.0.2 Release

Welcome to the **v1.0.2** release of **Ubuntu Hello**! This is a maintenance release addressing a critical bug in subprocess privilege management under setuid/PAM environments and cleaning up console output leaks.

---

## ✨ Key Enhancements in v1.0.2

*   **🔒 Subprocess Privilege Hardening in PAM**:
    *   Resolved a privilege-dropping bug where standard shells (like `dash`) drop effective root privileges to the calling user's UID when spawned via `popen()` inside PAM authentication contexts.
    *   Temporarily set the real UID (RUID) to `0` (`setreuid(0, 0)`) during subprocess execution in `try_set_keyring_authtok` and `pam_sm_setcred`, allowing keyring caching and TPM operations (`tpm2_createprimary`, `tpm2_load`, `tpm2_unseal`) to execute successfully with root authority.
    *   Ensured original user UIDs are restored immediately after forking to maintain security integrity.
*   **🧹 Silent Console Cleanups**:
    *   Suppressed diagnostic warnings and errors during the cleanup of transient TPM context files by redirecting the standard error of `rm` commands (`2>/dev/null`), ensuring a clean terminal output for users authenticating via CLI.

## 📥 Installation

### Method 1: Quick Install (Recommended)
Open your terminal and run the universal installer:
```bash
curl -fsSL https://raw.githubusercontent.com/ventura8/ubuntu-hello/master/install.sh | sudo bash
```

### Method 2: PPA (Ubuntu / Linux Mint)
```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello
sudo apt update
sudo apt install ubuntu-hello
```

### Method 3: Debian / Manual Package
Download the attached `.deb` package for your architecture, then install it using `apt` or `gdebi`:
```bash
sudo apt install ./ubuntu-hello_1.0.2-1ppa1_amd64.deb
```
